# Two-Layer SMD PCB Design

## Project Overview
This repository contains recovered materials from a two-layer PCB design assignment using surface-mount device (SMD) components, completed as part of electronics manufacturing and PCB design training.

## Project Materials
- **Gerber manufacturing archives:** Recovered ZIP files containing PCB manufacturing-layer data.
- **Assignment documentation:** PDF documents associated with the PCB design assignment.
- **Design evidence:** Original schematic and PCB screenshots, where available.

## Manufacturing Outputs
The recovered manufacturing archives are named:
- `assignment 2-B_Paste (1).zip`
- `assignment 2-F_Mask (1).zip`

These archives preserve part of the original manufacturing output. They should not be treated as a complete editable PCB project.

## Tools and File Availability
The recovered files include manufacturing data and assignment documentation. The complete original editable design files have not yet been verified.

## Notes
This repository preserves available materials from the original assignment for documentation, reference, and portfolio purposes.
